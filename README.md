📱 RoomApp – Modelo de Aplicativo Android com Login

--

📌 Descrição

Projeto desenvolvido como meu primeiro aplicativo Android, com foco na implementação de um sistema de login utilizando os recursos básicos do Android Studio.

O objetivo é servir como base para compreensão da estrutura de aplicações Android e autenticação simples de usuários.

--

🎯 Objetivo

Compreender a estrutura de um projeto Android

Implementar sistema de login básico

Trabalhar com navegação entre Activities

Aplicar conceitos fundamentais de interface com XML

Criar base reutilizável para projetos futuros

--

🛠️ Tecnologias Utilizadas

 Kotlin

Android Studio

Android SDK

XML para construção de layouts

Git e GitHub
